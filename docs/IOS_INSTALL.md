# iPhone・iPadへの導入

App Store は使いません。Safari からホーム画面に追加して使います。

---
<br/>
<br/>

## 追加する
1. Safari で `https://<GITHUB_OWNER>.github.io/catch-up-docs/` を開く
2. 画面下部（iPadでは上部）の共有ボタンを押す
3. 「ホーム画面に追加」を選ぶ
4. 名前を確認して「追加」を押す

ホーム画面にアイコンができます。**以降はそのアイコンから起動してください。**

Safari以外のブラウザ（Chrome、Edge など）からでも閲覧はできますが、通知を受け取るにはSafariからホーム画面へ追加する必要があります。

---
<br/>
<br/>

## 初期設定
ホーム画面のアイコンから起動すると、初期設定が始まります。

1. アプリ専用パスワードを決める（10文字以上）
2. 文書リポジトリのオーナー名とリポジトリ名を入れる
3. アクセストークンを貼り付けて接続テストを行う

**端末ごとに設定が必要です。** Androidで設定済みでも、iPhoneでは改めて設定します。データは端末の中だけに保存され、端末間では共有されません。

---
<br/>
<br/>

## 通知
iOS・iPadOS では、**ホーム画面に追加したアプリとして起動した場合にだけ** Web Push を使えます。通常のSafariのタブでは通知を受け取れません。

アプリの設定画面が、いまどちらの状態で開かれているかを判定して案内を出します。「ホーム画面へ追加してください」と表示された場合は、上の手順で追加し直してからもう一度開いてください。

通知の許可を求めるダイアログは、「通知を有効にする」ボタンを押したときにだけ出ます。ページを開いただけでは出ません。

登録の手順は `docs/PUSH_REGISTRATION.md` を参照してください。

## 動きの違い
| 項目 | 状態 |
|---|---|
| 文書の閲覧 | 通常のタブでもホーム画面からでも可能 |
| 通知 | ホーム画面から起動した場合のみ |
| 全画面表示 | ホーム画面から起動した場合のみ |
| データの保持 | ホーム画面のアイコンを削除すると消える |

ホーム画面からアイコンを削除すると、保存していた設定・トークン・既読情報も消えます。追加し直した場合は初期設定からやり直しになります。

## うまくいかないとき
| 症状 | 確認すること |
|---|---|
| 「ホーム画面に追加」が出ない | Safari で開いているか。他のブラウザでは表示されないことがある |
| 通知を有効にするボタンが押せない | ホーム画面のアイコンから起動しているか |
| 通知が届かない | 端末の設定 → 通知 で、このアプリの通知が許可されているか |
| 起動するたびにパスワードを聞かれる | 最後の認証から120時間が経っていないか。端末の日時が正しいか |

端末の日時を大きく変更すると、安全のためロックがかかります。日時を正しく戻してからパスワードを入力してください。
